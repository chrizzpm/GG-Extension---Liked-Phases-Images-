示例文章 · DEMO 《手账爱好者周刊》第 42 期

把整个互联网，剪成一本属于自己的册子

我们每天浏览大量网页：一段写得极好的文案、一张想用作参考的配图、一个或许以后用得上的教程。 浏览器书签只能记下网址，却留不住内容本身——页面改版、链接失效、文章被删，那些曾经打动你的片段就消失了。

「网页收藏家」做的事情很简单：把文字和图片原样剪下来，夹进你命名的目录。 设计灵感、旅行攻略、菜谱、读书笔记，各归其位。所有数据保存在浏览器本地，不上传任何服务器。

它不像冷冰冰的效率工具。米白纸张底色、墨绿主色、朱砂色的角标脉冲—— 每一次收藏都像把一张便利贴贴进本子。划词时浮现的小按钮、拖拽图片时呼吸的悬浮球， 都只在你需要时出现，绝不打扰阅读本身。

点击浏览器工具栏的扩展图标，你会看到完整的收藏管理界面：按目录筛选、全文搜索、 一键复制文字、下载图片、删除整理，还支持导出 JSON 备份与导入恢复。试着在上面的段落里划选一句话吧。

提示：本页演示数据保存在当前浏览器 localStorage 中；安装为正式扩展后，数据保存在扩展独立的 IndexedDB 中。

功能特性

围绕「剪藏」这一件事，做到顺手、可靠、可管理。

划词即收藏

鼠标划选网页任意文字，选区旁浮现墨绿收藏按钮，点击即可剪藏，自动过滤输入框等编辑区域。

图片角标与拖拽

悬停图片出现圆形收藏角标；也可以直接把图片拖到右下角悬浮球投放收藏，抓不到原图时自动降级保留原链接。

分类目录管理

收藏时选择或新建目录；弹窗中可筛选目录、全文搜索、复制文字、下载图片、重命名/删除目录。

本地安全存储

文字与图片以 Blob 形式存入扩展专属 IndexedDB，数据不离开浏览器；支持 JSON 备份导出与导入恢复。

右键菜单支持

选中文字或在图片上右键，即可从上下文菜单直接发起收藏，习惯哪种操作就用哪种。

Shadow DOM 隔离

所有注入界面运行在封闭 Shadow DOM 中，样式与宿主页面完全隔离，不会被任何网站 CSS 影响或污染页面。

安装指南

采用 Manifest V3，无需任何构建步骤，加载即用。

  1. 1

    下载扩展包

    点击右上角「下载扩展包」，得到 web-collector-extension.zip，解压到本地任意目录。

  2. 2

    打开扩展管理页

    在 Chrome / Edge 地址栏访问 chrome://extensions（Edge 为 edge://extensions）。

  3. 3

    开启开发者模式

    打开页面右上角的「开发者模式」开关。

  4. 4

    加载已解压的扩展程序

    点击「加载已解压的扩展程序」，选择解压出的 extension/ 目录即可。建议点击工具栏拼图图标把它固定到工具栏。

  5. 5

    开始剪藏

    打开任意网页：划选文字、悬停图片或右键菜单发起收藏；点击工具栏图标管理你的收藏册。
